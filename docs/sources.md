# Открытые источники уровней и материалов

Что можно взять для игр и учёбы, под какой лицензией и что из этого сделать. **Перед подключением — проверить лицензию на первоисточнике** (часть фактов ниже — из вторичных обзоров, это отмечено).

## Готовые уровни и задачи

| Источник | Что там | Лицензия | Что сделать в «Аркаде» |
|---|---|---|---|
| [Lichess puzzle database](https://database.lichess.org/) | ~6 млн шахматных задач с рейтингом сложности и темами (мат в 2, вилка…) | CC0 (общественное достояние; на странице «Puzzles by openings» Lichess прямо называет их public domain — [lichess.org](https://lichess.org/training/openings)) | «Шахматные задачи»: бесконечные уровни по рейтингу задач — идеально ложится на нашу систему уровней (уровень → диапазон рейтинга) |
| [Simon Tatham's Portable Puzzle Collection](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/) ([лицензия](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/licence.html)) | ~40 логических головоломок с **генераторами** уникальных задач (Net, Bridges, Light Up, Towers, Keen, Slant…) | MIT (у портов встречаются файлы с другими лицензиями — смотреть заголовки) | Портировать генераторы (C → JS) — сразу десяток головоломок с бесконечными уровнями и гарантированно единственным решением |
| Sokoban: Microban / Sasquatch (David W. Skinner) — [список библиотек SokoSolve](https://sokosolve.sourceforge.net/libraries.html) | сотни классических уровней «сокобана» от лёгких до очень сложных | **Не открытая лицензия**, а разрешение автора на распространение с указанием авторства | Можно, но для коммерческого использования лучше спросить автора. Альтернатива — свой генератор уровней |
| [Open Trivia Database](https://opentdb.com/api_config.php) | тысячи вопросов викторины по категориям (на английском), API без ключа, до 50 вопросов за запрос | CC BY-SA 4.0 (по описанию API и словам владельца — [форум](https://forums.pixeltailgames.com/t/what-am-i-allowed-to-do-with-the-content-from-opentdb/26248)) | Английская викторина / материал для «Английского». ShareAlike: производные наборы вопросов должны остаться под CC BY-SA, нужна атрибуция |

## Что подключать первым

1. **Lichess-задачи** → игра «Шахматные задачи» с бесконечными уровнями по рейтингу (CC0, без обязательств).
2. **Генераторы Тэтхэма** → 5–10 новых логических головоломок с единственным решением (MIT).
3. **Twemoji для флагов** → флаги видны на любом устройстве.
4. **Tatoeba** → колоды фраз для английского.

Правило для всего: в `docs/credits.md` фиксировать источник, автора и лицензию каждого подключённого набора; материалы CC BY-SA/ODbL хранить отдельно (у них share-alike).
